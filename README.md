# 王聪聪 · 个人作品集

React + Vite 个人作品集。版心最大 1700px，包含全屏视频首页、个人介绍与经历、精选作品、个人优势、整屏联系方式，并补充了窄屏适配。

## 运行

在此目录打开终端：

```powershell
npm install
npm run dev
```

也可以双击 `启动预览.cmd`。以终端实际打印的 Local 地址为准，默认地址是 http://127.0.0.1:5173 。保持该终端运行即可继续访问，关闭终端会停止预览。

## 构建

```powershell
npm run build
npm run preview
```

构建结果在 `docs/`，供 GitHub Pages 从 main 分支的 /docs 目录发布。不要直接双击 index.html，应通过 Vite 或静态 HTTP 服务访问。

## 后续修改

- `src/content.js`：姓名、联系方式、项目说明、经历和能力卡片。
- `src/main.jsx`：页面结构、分类筛选、视频和图片弹窗、邮箱复制。
- `src/styles.css`：配色、字体、版心、布局和移动端样式。
- `src/motion.css`：遮罩层、图片视差层、导航玻璃背景、按钮填充与动效降级样式。
- `src/usePortfolioMotion.js`：GSAP 开场、ScrollTrigger 单次进场、图片和鼠标视差、Lenis 平滑滚动。
- `src/AmbientParticles.jsx`：72 个 Canvas 粒子，限制 DPR 和绘制频率，离开首屏及页面隐藏时停止。
- `src/motionVisibility.js`：页面隐藏、恢复与视频暂停状态的生命周期处理。
- `public/assets/`：已本地化的人像、封面和 H.264 网页视频副本。

图片及网页视频来自项目提供的作品集素材，原始素材没有修改。

## 内容边界

- 姓名、邮箱、电话、教育及工作背景来自用户提供的简历；对外身份使用用户指定的“短视频编导 / AIGC 编导”。简历运营经历保留其原有岗位性质。
- “02 部完整视频 / 约 03:44 总时长 / 01 张摄影作品”来自本次实际素材，不代表累计商业项目数量或传播成果。
- 两支视频尚未提供正式名称、项目背景、日期及本人职责，暂命名“作品 01 / 作品 02”；没有虚构项目成果。
- 《爱人错过》标题及摄影署名来自作品图片，目前仅提供图片，按图片展示，不设置虚假视频入口。
- 首页创意形象使用用户提供的 AI 生成图片，保留原图标记并加注说明。
- 网站准备发布至指定 GitHub Pages；后续仍可补齐项目名称、职责和成果数据。

## 交互

导航点击可跳转模块；视频卡片打开原生播放器；摄影卡片放大图片；弹窗支持关闭按钮、Esc 和点击遮罩关闭；关闭后焦点回到原入口；邮箱可复制或调用邮件应用；电话可调用系统拨号应用。首页提供背景视频暂停按钮，并遵循减少动态效果偏好。

## 动效版本

- 使用 GSAP 3 + ScrollTrigger、Lenis；首屏时间线约 2.9 秒。视频约 1 秒渐入，双行标题 1.45 秒遮罩揭幕、上移与缩放，错开 0.15 秒；副标题在标题约 60% 进度时开始，CTA 与右下标语对向滑入，导航最后落下。
- 模块在顶部进入视口约 74% 位置时触发。标题遮罩与逐字位移先行，随后内容错峰展开；卡片上移并带桌面端轻微 rotateX，图片横向揭幕。采用 expo.out、power3.out、power2.out；滚动视差使用线性映射加 scrub 平滑。
- 仅插值 transform、opacity、clip-path。字距变化以逐字 x 位移模拟，不逐帧改 letter-spacing。导航用背景层 scaleY 和内容位移模拟收缩，静态 blur 层只做透明度切换，不动画化高度或 blur。
- 图片滚动视差范围 -5% 至 5%。作品封面使用独立滚动、鼠标和缩放层，鼠标位移限制在约 ±11px / ±9px；保留图片过扫描边缘。二维码和弹窗媒体保持静止，避免影响扫码、阅读及播放。
- 进场 ScrollTrigger 均为 once:true，并按模块及作品 ID 记忆，过滤、回滚或跨越断点时不会重复播放已触发的进场。连续视差独立运行。
- 低于 768px 关闭视差、3D、鼠标跟随、粒子和 Lenis，使用原生滚动；减少动态偏好下跳过进场和连续装饰效果。保留正常阅读、键盘导航和视频操作。
- 粒子固定 72 个，DPR 最大 2，每秒最多绘制约 30 次；只在桌面、首屏可见、页面可见且未启用减少动态效果时绘制。滚动与 GSAP 使用同一时钟；组件销毁和断点变化会移除监听器、观察器和补间。
- Page Visibility API 隐藏时暂停运动、视频、粒子和平滑滚动；恢复时保留手动暂停状态。视频弹窗打开期间锁定底层滚动，弹窗仍可滚动和关闭。

运行 `npm test` 可检查隐藏/恢复状态：手动暂停不被覆盖、弹窗保持锁定、已移除的视频不恢复、初始隐藏及事件清理。当前 3 项状态测试通过。内置浏览器切换标签没有暴露 hidden=true，因此系统级隐藏行为以状态测试验证，尚未做独立浏览器和低性能真机帧率测试。
